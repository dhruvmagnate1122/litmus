# Litmus roadmap

The roadmap prioritizes evidence quality over checklist size.

## v0.1.x — make the baseline dependable

- improve report readability and machine-readable schema stability;
- add explicit accepted/deferred-risk records;
- add fixture projects for common web stacks;
- add false-positive regression cases;
- document pack versioning and compatibility;
- add CI workflow for the test suite.

## v0.2 — evidence adapters

- Playwright/browser runtime evidence;
- Lighthouse / Core Web Vitals ingestion;
- dependency/SCA evidence adapters;
- HTTP crawl/SEO adapter;
- database/query-profiler evidence format;
- GitHub Actions integration.

## v0.3 — ecosystem packs

Candidates, only with maintainers and evidence models:

- Next.js;
- Supabase/Postgres;
- Firebase;
- Django;
- Rails;
- Laravel;
- static/Jamstack sites.

## Later

- AI/LLM application-security pack;
- native-mobile packs;
- hosted dashboard/history;
- release-to-release regression comparison.

No roadmap item is a promise or release date.
